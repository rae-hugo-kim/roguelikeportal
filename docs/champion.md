# 우승자 배너를 운영합니다.

## 이번 변경을 설명합니다.

현재 회차 탭, Google OAuth 로그인, 관리자 기록 입력·발송과 브라우저의 봇 동기화를 제거했습니다. 룰렛, 기준일 필터, 결과 복사, 기록 조회, 참가자 통계와 경기장 정보는 유지합니다. 유효스킬 조회는 `skill-by-track.json`만 사용합니다.

최상단에는 가장 최근에 완료된 회차의 우승자 닉네임, 우승 말딸의 공식 이름·의상 타이틀·이미지를 표시합니다. 원형 배경만이 아니라 배너 전체와 글자·버튼·장식 색이 공식 이미지의 대표색에 맞춰 바뀝니다. 배너 밖의 페이지는 기존 밝은 녹색 계열을 유지합니다.

운영 화면에는 검토용 의상 선택 메뉴나 색상 진단 표시를 넣지 않았습니다. 외부 봇의 채팅 수집·데이터 배포와 Google Cloud의 자격 증명 자체는 변경하지 않았습니다.

## 데이터 갱신 경로를 유지합니다.

- `index.html`의 `const DATA`, `supportCards`, `characters`, `trackData`는 계속 인라인으로 유지합니다. 기존 봇의 DATA 주입과 `scripts/sync_gametora.py`의 상수 갱신 경로를 변경하지 않았습니다.
- 완료된 회차는 결승에 `rank: 1`과 참가자 이름이 있는 기록으로 정의합니다. 그중 가장 큰 회차 번호를 선택하므로 배열 순서나 기록 시각에 의존하지 않습니다.
- 봇이 새 DATA를 배포한 뒤 페이지를 열거나 새로고침하면 새 우승자로 전환됩니다. 별도 수동 우승자 설정이나 실시간 봇 API는 필요하지 않습니다.
- `champion.js`는 기록·참가자 링크와 이미지 로드를 담당하고, `champion-core.mjs`는 우승자 선택·옷갈 매칭·대표색과 테마 계산을 담당합니다. `champion.css`는 승인한 반응형 디자인을 적용합니다.

## 옷갈과 공식 명칭을 연결합니다.

기록에 `card_id`가 있으면 해당 ID를 우선합니다. 없으면 육성마 목록의 기존 이름 또는 공식 이름과 의상 타이틀 전체로 매칭합니다. 공백·유니코드·영문 대소문자는 정규화하지만 `(수영복)` 같은 의상 구분은 제거하지 않습니다.

알 수 없는 ID나 별명, 중복 후보에는 다른 의상을 임의로 표시하지 않습니다. 예를 들어 `메지로라모누`는 기본 의상 이름과 일치하지만, 그것만으로 당시 실제 출전 의상이 기본인지 웨딩인지 입증할 수는 없습니다. 실제 의상을 확정하려면 수집된 기록에 의상 정보가 있어야 합니다.

`character-labels.json`은 card_id별 공식 이름·타이틀·GameTora 출처를 저장합니다. 다음 명령은 육성마 목록과 같은 디렉터리의 공식 명칭 파일도 함께 갱신합니다.

```sh
python3 scripts/sync_gametora.py characters --apply --images-dir <image-repo>/images/characters
```

`--index`를 지정하면 공식 명칭 파일도 해당 HTML 옆에 생성합니다. 이미지는 기존 `keiaaskim/uma-race-system` 저장소의 PNG를 계속 사용합니다. 이미지를 추가하는 PR이 머지되기 전에는 해당 이미지가 제공되지 않을 수 있습니다.

## 대표색을 안전하게 적용합니다.

원본 이미지는 512×512로 표시하고 분석용 Canvas만 64×64로 축소합니다. 투명 영역·흰색·검은색·저채도 픽셀을 제외하고 의상 쪽 색에 가중치를 줍니다. 인접 색상 구간을 묶기 때문에 빨강의 0도·360도 경계도 같은 색상군으로 취급합니다.

같은 색상 계열에서 배너 바탕은 어둡게, 이미지 뒤 원은 밝게, 글자와 버튼은 대비가 나도록 보정합니다. 피부나 의상을 의미적으로 인식하는 모델은 아니므로 소품 색도 반영될 수 있습니다. 이미지 실패·색 읽기 차단·뚜렷한 유채색 부재 시에는 기본 배경과 안내를 사용합니다. 늦게 도착한 이전 이미지가 새 이미지를 덮어쓰지 않도록 요청 번호를 확인합니다.

## 검증 방법을 남깁니다.

```sh
node --test tests/champion-core.test.mjs
python3 -m http.server 8769 --bind 127.0.0.1
```

자동 테스트 13개는 우승자 선택, ID 우선순위, 옷갈 이름과 공식 타이틀, 모호한 매칭, 투명·무채색 이미지, 색상 경계와 WCAG AA 대비를 검증합니다. 배너의 글자·버튼은 색상환을 5도 간격으로 순회하고 채도·광원 강도를 조합해 4.5:1 이상의 대비를 확인합니다.

운영 HTML을 실제 Chromium으로 열어 최신 우승자, 새 완료 회차 전환, 수영복 옷갈 이미지, 회차·참가자 링크, 룰렛과 실제 복사·붙여넣기, 정적 스킬 검색, 경기장 119개 코스를 확인했습니다. 320·390·768·1440px 레이아웃과 미확인 ID·색 읽기 차단도 확인했습니다. 제거한 Google 인증과 봇 API 요청은 발생하지 않았습니다.

실제 GameTora 동기화는 임시 HTML 사본으로 실행해 신규 육성마와 공식 명칭이 함께 생성되는 것을 확인했습니다. 검증용으로 받은 신규 육성마는 운영 풀에 추가하지 않았습니다.
