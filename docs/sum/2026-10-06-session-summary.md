## 배포 상태를 정리합니다.

승인한 우승자 배너와 기능 정리를 운영 사이트에 적용하고, main에 커밋·push한 뒤 Vercel 배포까지 확인했습니다.

- 운영 사이트는 https://roguelikeportal.vercel.app/ 입니다.
- 기능 반영 커밋은 `ef111ea`이며, 메시지는 `feat: 현재 회차 기능을 제거하고 우승자 배너를 적용합니다`입니다.
- 이전에 남아 있던 마장 복사 형식 수정은 `b0d88d8`로 보존해 함께 push했습니다.
- 배포 검증 당시에는 135개 회차와 435회 우승자 소리 님, 메지로 라모누의 공식 이미지·배너 테마를 확인했습니다. 이 수치는 당시 검증 결과이며 이후 자동 갱신될 수 있습니다.
- 이 요약을 저장하기 전에 원격의 `b7a970f`(2026-10-05 봇 데이터 자동 업데이트)를 fast-forward로 반영했습니다. 해당 자동 갱신의 데이터는 수정하지 않았습니다.

## 현재 회차 기능을 제거했습니다.

현재 회차 탭, 관리자 기록 입력·결과 발송, Google OAuth 로그인과 브라우저의 봇 동기화를 제거했습니다. 룰렛, 클립보드 복사, 통계, 참가자 전적과 경기장 정보는 유지했습니다. 유효스킬 조회는 `skill-by-track.json`만 사용합니다.

별도 채팅 수집 봇, 서버 API와 Google Cloud의 자격 증명 자체는 삭제하지 않았습니다. 사이트에서 사용하지 않는 연동을 제거한 것이며, 외부 봇의 채팅 수집·기록 배포는 유지합니다.

## 최신 우승자 배너를 적용했습니다.

결승에 `rank: 1`과 참가자 이름이 있는 기록 중 가장 큰 회차 번호를 선택합니다. 배열 순서나 기록 시각에 의존하지 않습니다.

닉네임, 우승 말딸의 공식 이름·의상 타이틀·이미지, 회차·날짜·코스를 표시합니다. 우승 기록과 참가자 전적으로 이동하는 링크도 제공합니다. 다른 탭으로 이동하면 배너를 접어 기능 사용 공간을 확보합니다.

이미지에서 대표색을 추출해 원형 배경만이 아니라 배너 전체·글자·버튼·테두리·장식 링·배지·그림자에 적용합니다. 배너 밖의 페이지는 기존 밝은 녹색 계열을 유지합니다.

- 분석용 Canvas만 64×64로 축소하고 원본 이미지는 그대로 표시합니다.
- 투명 영역, 흰색·검은색·저채도 픽셀을 제외하고 의상 쪽 색에 가중치를 줍니다. 소품 색도 반영될 수 있습니다.
- 배너 바탕은 어둡게, 원형 배경은 밝게 보정하고 글자·버튼 대비를 유지합니다.
- 이미지 또는 색 읽기가 실패하면 기본 배경과 안내를 사용하며, 다른 의상의 이미지로 임의 대체하지 않습니다.
- 검토용 의상 선택 메뉴·색상 진단 표시·중복 데이터 사본과 임시 서버는 운영 반영 후 정리했습니다.

## 옷갈과 공식 명칭을 연결합니다.

기록에 `card_id`가 있으면 우선 사용합니다. 없으면 육성마 목록의 기존 이름이나 공식 이름과 의상 타이틀 전체를 비교합니다. 유니코드·공백·영문 대소문자는 정규화하지만 `(수영복)` 같은 의상 구분은 제거하지 않습니다.

알 수 없는 ID나 별명, 중복 후보에는 임의의 의상을 붙이지 않습니다. 다만 기록에 의상 정보가 없다면 실제 출전 의상까지 확정할 수는 없습니다. 예를 들어 435회에 저장된 `메지로라모누`는 기본 의상 이름과 일치하지만, 그 기록만으로 실제 출전 의상이 기본인지 웨딩인지 입증할 수는 없습니다.

`character-labels.json`은 card_id별 공식 이름·의상 타이틀·GameTora 출처를 저장합니다. `characters --apply` 실행 시 육성마 목록과 함께 갱신되도록 연결했습니다.

## GameTora 수집·갱신 흐름을 유지합니다.

서포트 카드는 SSR만 수집하고, 육성마는 의상별 카드 데이터를 사용합니다. 기존 이름은 유지하며 신규 항목은 공식 명칭으로 생성합니다. 신규 추가 시 `--alias`로 금딱 스킬명이나 의상 별명을 지정할 수 있습니다. 자동 별명 후보가 여러 개면 직접 지정해야 합니다.

`added`는 한섭 출시일 기준으로 사용하고 룰렛은 기본적으로 접속 PC의 오늘 날짜까지 필터링합니다. 기존 항목에는 임시 과거 기준일 `2026-02-10`을 유지했습니다. 미출시 항목에는 GameTora 예측 출시일을 사용할 수 있으므로 실제 확정일과 다를 수 있습니다.

이미지는 기존처럼 `keiaaskim/uma-race-system` 저장소에 PR로 추가하고 raw URL로 사용합니다. 서포트 이미지 PR #1과 육성마 이미지 PR #2는 머지됐습니다.

```sh
python3 scripts/sync_gametora.py supports
python3 scripts/sync_gametora.py characters
python3 scripts/sync_gametora.py tracks
```

기본 실행은 미리보기이며 파일 반영에는 `--apply`를 사용합니다. 이미지를 받을 때는 `--images-dir`로 이미지 저장소의 해당 디렉터리를 지정합니다. `characters --apply`는 지정한 HTML 옆의 `character-labels.json`도 함께 생성·갱신합니다.

봇 배포와 기존 동기화 스크립트가 계속 사용할 수 있도록 `DATA`, `supportCards`, `characters`, `trackData`는 `index.html` 안에 인라인으로 유지했습니다. 검증 중 임시 사본에 추가된 신규 육성마는 운영 풀에 반영하지 않았습니다.
